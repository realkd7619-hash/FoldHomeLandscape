# Fold Home Landscape

Galaxy Z Fold에서 **펼친 내부 화면의 홈 화면만 가로 고정**하고, 앱에서는 자동 회전을 유지하는 실험용 앱입니다.

- 내부 화면 + One UI Home → 가로 고정
- 내부 화면 + 다른 앱 → 자동 회전
- 접힌 외부 화면 → 자동 회전
- Home Up DIY 사용 가능

## 설치
GitHub Actions가 APK를 빌드합니다. Actions 실행이 끝나면 Artifacts에서 APK를 받을 수 있습니다.

## 주의
Samsung One UI/기기 버전에 따라 시스템 회전 API 동작이 달라질 수 있습니다.
